# Ø30mm 볼 트랜스퍼 조립 시제품

SO-101이 하부 하우징에 볼을 넣고 덮개를 씌우는 실험용 CAD입니다. 공유 대화의 3부품 개념을 바탕으로 새로 설계했으며 상용 제품을 복제한 도면은 아닙니다. 작은 지지 볼을 생략한 **미끄럼 컵 방식**입니다. 실제 출력·마찰·하중·로봇 집기 시험은 아직 수행하지 않았습니다. 산업용 베어링의 정격 하중이나 이동 성능을 갖는다고 보장하지 않습니다.

## 주요 치수 (mm)

- 볼: Ø30, 볼 중심 조립 높이 18, 볼 꼭대기 높이 33.
- 하우징: 50×50×23, 외곽 수직 모서리 모따기 2.
- 덮개: 50×50, 판 두께 5, 아래 정렬 턱 포함 높이 7.7.
- 완성품: 50×50×33. 덮개 상면 28, 볼 돌출 5.
- 컵 반지름: 15.35. 바닥 최소 두께 3. 볼은 중력에 의해 컵 바닥에 접촉.
- 볼 이탈 방지 구멍: Ø26. 덮개 내부는 구면으로 파여 볼과 간섭하지 않음.
- 덮개 정렬 턱: 끝 Ø40.4 → 뿌리 Ø41.6, 삽입 길이 2.7.
- 하우징 정렬 홈: Ø42.6, 깊이 3. 반경 여유 0.5.
- 자석 홈: Ø6.3 × 깊이 2.2, 중심 좌표 (±19, ±19), 하우징·덮개 각 4개.
- 선택 지그: 하우징 포켓 50.8, 포켓 바닥 높이 4, 입구 유도 경사. M4용 Ø4.5 관통구 중심 (±29, ±29). 양옆 손가락 접근 홈 폭 24.

## 추가 부자재와 고정 방식

자석은 **Ø6×2mm 원형 자석 8개**를 사용합니다. 하우징 4개와 덮개 4개에 서로 끌어당기는 극성으로 미리 접착합니다. 자석과 접착제는 로봇 조립 이전에 설치하는 부자재이며 로봇 투입 단위가 하우징·볼·덮개 3개입니다. 금속 부품 없는 3개짜리 스냅핏이 아닙니다.

자석 윗면은 플라스틱 결합면보다 약간 낮게 두고 돌출시키지 마세요. 등급에 따라 체결·분리력이 달라지므로 약한 자석으로 먼저 시험합니다. 접착제 경화와 극성을 확인한 뒤 로봇 작업을 시작합니다. 자석이 없으면 덮개는 얹힌 상태이므로 운반 중 볼 이탈 방지가 보장되지 않습니다.

## 출력 시작 설정

일반적인 0.4mm 노즐 FDM 프린터를 가정한 시작값이며 프린터에 맞게 조정합니다. STL 단위는 mm, 슬라이서 배율은 100%입니다.

- 하우징·덮개: PLA 또는 PETG, 레이어 0.16~0.20mm, 벽 4겹, 상하단 5겹, 인필 25~35%. 제공 방향으로 출력하면 내부 서포트 없이 시도 가능. 슬라이서에서 하우징 컵 바닥의 오버행을 확인합니다.
- 볼: PLA, 레이어 0.10~0.12mm, 벽 4겹, 인필 15~20%, 서포트와 브림 사용. 완전한 구이므로 바닥 접촉이 작고 하부 서포트 자국이 생깁니다. 서포트 제거 후 접촉 자국·이음매를 고운 사포로 정리합니다. 구를 평평하게 잘라 출력하면 회전 시 걸릴 수 있습니다.
- 지그: PLA, 레이어 0.20mm, 벽 4겹, 인필 25%, 별도 서포트 없이 출력.
- 최초에는 한 세트만 출력합니다. 전체 배율을 바꿔 끼워맞춤을 조절하지 말고 원본의 컵 여유·정렬 턱 치수를 수정합니다.

매끄러운 시판 Ø30mm 수지 구로 출력 볼을 대체해도 됩니다. 실제 지름을 측정한 뒤 사용하세요. 금속 구는 무게가 늘어나므로 별도 집기 시험이 필요합니다.

## 조립과 로봇 작업

1. 먼저 손으로 볼을 컵에 넣고 자유롭게 회전하는지 확인합니다.
2. 자석을 사전 접착한 덮개를 턱에 맞춰 내려놓습니다. 덮개 면이 하우징 상면에 닿고 볼이 계속 돌아가는지 확인합니다.
3. 하우징을 지그에 놓습니다. 지그는 위치 안내용 여유 끼워맞춤이며 위로 들리는 것을 막는 클램프는 아닙니다. 지그 바닥이 4mm이므로 지그 사용 시 모든 조립 Z 좌표에 4mm를 더합니다.
4. SO-101은 볼 집기 → 컵 입구에 접근 → 저속 내려놓기 → 집게 해제 → 덮개 집기 → 정렬 턱 삽입 → 완료 순서로 움직입니다.
5. 덮개는 외곽 평면을 집는 구조로 집는 폭 50mm, 평평한 가장자리 높이는 5mm입니다. 실제 집게가 이 폭을 벌릴 수 있는지, 자석에 끌려 내려갈 때 손가락이 하우징과 부딪히지 않는지 확인합니다. 볼에는 오목한 패드가 유리합니다. 집게 형상이 제공되지 않아 충돌 검증은 포함하지 않았습니다.
6. 완성품을 운반할 때는 하우징을 잡거나 팔레트째 옮깁니다. 덮개만 잡아 들어올리면 자석 결합이 풀릴 수 있습니다.

덮개 정렬 턱은 정밀 위치결정을 돕지만 큰 위치 오차를 자동 보정하지 않습니다. 집게가 강하게 구속한 상태에서 억지로 누르지 않습니다.

## 기능 시험

- 무하중에서 손으로 볼을 세 방향으로 회전시켜 걸림을 확인합니다.
- 한 개의 볼 위에 판을 놓으면 불안정하므로, 판 이동 시험은 동일 높이의 유닛 최소 3개로 받칩니다.
- 가벼운 빈 판부터 시작하고 볼에 표시를 해 실제로 회전하는지 관찰합니다. 판만 볼 위에서 미끄러지는 것은 구름 기능 성공으로 세지 않습니다.
- 출력 구와 컵 사이의 마찰 때문에 무게를 올리면 회전하지 않을 수 있습니다. 이 경우 표면 마감·재료 조합을 바꾸고 재시험합니다. 작은 지지 볼을 넣는 베어링 방식은 별도 설계가 필요합니다.
- 로봇 조립 20회 동안 집기 성공, 볼 삽입, 덮개 완전 안착, 조립 후 회전 성공을 따로 기록합니다.

## CAD 수정

Python 환경에서 `pip install cadquery trimesh` 후 `python build_model.py`를 실행하면 같은 폴더에 STL·STEP·검사 JSON을 다시 생성합니다. 주요 끼워맞춤 파라미터는 파일 상단에 있습니다. 외형과 볼 지름을 크게 바꾸면 덮개 구멍·자석 위치 등 연동 치수도 재설계해야 합니다. 원본은 Ø30mm 설계 기준입니다.
