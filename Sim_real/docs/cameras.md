# 시뮬레이션 카메라

`final` 실행 후 `scripts/assembly.sh manual`로 시작하면 세 카메라가 함께 켜진다.
브라우저에서 http://127.0.0.1:8766/ 접속. 녹화/재생 모드에서도 같은 화면을 제공한다.

- 탑뷰: 두 작업대 전체를 수직으로 관찰. 고정 지지대는 시각 모델이며 충돌하지 않는다.
- SO-101: 기존 wrist_camera_link에 부착, 팔을 따라 이동한다.
- OMX: link5 위에 부착, 그리퍼 몸체의 높이를 피해 양쪽 손가락을 바라본다.
- 각 640×480 RGB, JPEG 최신 프레임을 최대 10Hz로 갱신. 실제 갱신 속도는 렌더링 부하에 따라 낮아질 수 있다.
- 화면 일시정지는 브라우저만 멈춘다. 로봇 제어/포스피드백은 계속된다.
- 1초 이상 오래된 영상은 지연으로 표시. 시뮬레이터 종료 시 연결 대기로 표시한다.

카메라 외부/내부 파라미터와 OMX 브래킷은 시뮬레이션용 근사값이다. 실물 카메라 보정값이 아니다.
영상은 메모리에만 저장하며 현재 동작 JSONL 녹화에 이미지가 포함되지는 않는다.
일반 로봇 장면에서는 `scripts/sim.sh --live-cameras`로 켤 수 있다.
카메라 없이 성능 비교: `scripts/sim.sh --scene assembly --mode manual`.
HTTP 서버는 127.0.0.1에만 열리며 실물 모터에 접근하지 않는다.

## 실행 검증 (2026-09-10)
세 영상의 실제 화면과 일시정지/재개 동작을 확인했다. 10초 측정에서 시뮬레이션 실시간 비율은 0.947,
ROS joint_states 약 18.94Hz, 접촉 메시지 수신 지연 중앙값 7.15ms/최대 10.98ms였다.
물리 스텝은 120Hz, 렌더링은 6스텝마다 수행한다. 측정값은 현재 PC 및 장면 기준이며 보장값은 아니다.
`outputs/camera_validation.json`에 결과를 저장했다. 기존 자동 테스트 35개와 스트림 초기 대기/JPEG/신선도 확인을 통과했다.
