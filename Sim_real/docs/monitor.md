# 다크 모드 통합 모니터

사용자 승인 구성: 큰 시뮬레이션 전체 영상, 선택형 손목 영상, 우측 실물 진단 패널.
기본 다크 모드이며 영상과 상태를 두 개 이상 창으로 나누지 않고 확인한다.

## 실행

```bash
# 전체 공정 + 통합 모니터 (USB/모터 없이 실행)
/path/to/Final_Arm/Sim_real/scripts/factory.sh

# Isaac 편집 창 없이, 통합 모니터에서 영상으로 보기
/path/to/Final_Arm/Sim_real/scripts/factory.sh --headless

# 이미 실행 중인 카메라·수집 프로그램을 보는 모니터만 실행
/path/to/Final_Arm/Sim_real/scripts/monitor.sh
```

브라우저에서 http://127.0.0.1:8767/ 를 연다.
기존 `finalrun`도 같은 통합 모니터를 시작한다. `assembly.sh manual`을 단독으로 사용하는 경우 `monitor.sh`를 함께 실행한다.
기존 카메라(8766)·전압(8765) 화면도 유지한다.
시뮬레이션 내부 편집·마우스 궤도 조작 대신 시뮬레이션의 실제 렌더 영상을 웹에 표시한다.
전체 시점 전환과 영상 크게 보기는 가능하다.

모니터는 기존 서버 값을 조회하며 시리얼 장치를 열거나 모터 명령을 보내지 않는다.
`factory.sh`는 실물 수집 프로그램을 시작하지 않는다. 기존 수집기를 사용자가 실행하면
실물 값이 들어오고, 미연결 상태에서는 `—`와 연결 대기를 표시한다.
기존 `finalrun`의 리더/포스피드백 동작은 그대로이며 모니터 기능이 새로 모터 출력을 활성화하지 않는다.

## 표시하는 값

- SO-101: 기존 전압 수집기의 모터 6개 전압, 최소 전압, 부하 원시값, 온도, 통신 오류 및 오류 이력.
  모터 이름을 누르면 최근 60초 전압을 표시한다.
- STS 부하: 기존 56–70번 레지스터 응답 안의 Present_Load(60–61)를 사용한다.
  bit 10 부호·크기 형식은 포함된 LeRobot `motors/feetech/tables.py` 기준이다.
  추가 시리얼 읽기 없이 표시하며, N·N·m 단위로 환산하지 않는다. 기존 CSV 형식은 유지한다.
- OMX: 기존 `omx_haptics_status.json`의 그리퍼 ID 6 전압·온도·현재/목표 전류(mA), 포스피드백 상태.
  다른 OMX 관절의 부하는 현재 수집하지 않는다. 전류 그래프는 통합 창을 연 뒤 쌓인다.
- 실물값은 실제 수집 대상 리더 1대씩의 값이다. 공정 팔 A/B/C/D 4대의 실물 측정값으로 복제하지 않는다.
- 카메라는 전체 2시점 + 손목 RGB 2개 + 깊이 시각화 2개 중 선택한다.
  RGB와 깊이는 같은 센서의 출력이므로 물리 카메라가 6대로 늘어난 것이 아니다.
  기존 장면에서는 탑뷰·SO-101·OMX 3영상도 자동 인식한다.

## 연결·일시정지·종료

SO-101 현재값은 마지막 응답 0.75초 초과 시, OMX 상태는 기록 3초 초과 시 지운다.
기존 SO-101 수집기는 먼저 0.5초 기준으로 stale 처리한다. 카메라가 2초 이상 오래되면 대기 상태로 전환한다.
화면 일시정지는 표시만 멈춘다. 수집·시뮬레이션·모터 동작을 멈추는 버튼이 아니다.

시뮬레이션이 시작한 모니터는 시뮬레이션 종료와 함께 닫힌다.
`monitor.sh`로 먼저 실행한 모니터는 재사용하며 시뮬레이션 종료 후에도 연결 대기로 남는다.
각 실행 터미널에서 Ctrl+C로 종료한다.
같은 카메라 포트(8766)를 쓰는 기존 장면과 전체 공정 장면은 동시에 실행하지 않는다.

구현: `arm_sim/monitor.py`, `web/monitor.html`, `web/monitor.css`, `web/monitor.js`.
외부 웹 서비스·CDN·패키지 설치 없이 동작하며 127.0.0.1에만 바인딩한다.

## 검증 기록 (2026-09-13)

- 회귀 검사 포함 테스트 50개 통과. 부하 부호 해석, 전압 0과 미수집 구분, 시간 초과 값 제거, OMX 파일 누락·만료, 모든 수집기 미실행 상태의 HTTP 응답 검증.
- 실제 Isaac 전체 공정의 6영상 및 기존 조립 장면의 3영상 수신 확인.
- 브라우저에서 카메라 선택, SO-101/OMX 전환, 일시정지/재개, 서버 종료 감지 확인.
- 실물과 분리한 테스트 전용 서버로 저전압 경고, 부하 -73/0 표시, 그리퍼 전류·포스피드백 표시, 만료 후 수치 제거를 확인했다. 실제 실물 모터 측정 검증은 아니다.
- 390px 폭에서 가로 넘침 없음, 보이는 조작부 높이 44px 이상 확인. 일반 화면에서 두 영상과 우측 진단 배치를 확인했다.
- Impeccable 컨텍스트 실행기는 권한 문제로 실행되지 않았다. 기존 코드·승인한 다크 테마를 기준으로 수동 화면 검토를 수행했다.

전체 공정 데모 실행 시 가상 공정만 일시정지·재개·초기화하는 버튼을 추가로 표시한다.
실물 진단은 계속 조회 전용이며, 버튼은 모터 명령을 보내지 않는다. 사용법은 `docs/demo.md`를 참고한다.
