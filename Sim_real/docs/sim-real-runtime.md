# 2026-09-16 Sim_real 공정 연결

실행·치수·한계는 [README](../README.md)를 기준으로 합니다.

- `arm_sim/real_demo.py`: 기존 DemoPlan의 시간 보간·작업 예약을 재사용하는 새 부품/기구 전용 계획. 재료 18개, 용기 2개를 고유 객체로 관리합니다.
- `arm_sim/real_transfer.py`: A의 들어 올린 두 자세 사이를 실제 메시로 확인합니다. 직선 관절 경로가 간섭하면 어깨·팔꿈치 경유점을 먼저 검사하고, 필요한 경우 고정 난수 시드로 경로를 찾습니다. 최종 보간 경로는 별도 전체 형상 검사로 다시 확인합니다.
- `arm_sim/real_vehicle.py`: 전진 U자 경로의 모서리를 곡선으로 연결하고 차량 위치·방향의 속도와 가속도를 제한합니다. 도킹·승강은 양 끝에서 정지하는 5차 보간을 사용합니다.
- `scripts/check_real_docking.py`: 전진 도킹·회전 전 직선 후진 이탈을 검사합니다. 지게차의 포크·용기를 포함한 전체 회전 반경과 받침대 앞쪽 여유, 운반로봇 방향 변경 전후의 초기 부품 위치도 비교합니다.
- `scripts/real_sim.py`: 실제 URDF와 최신 카메라·클램프·지게차 형상을 생성하고 관절 및 차량/부품의 장면 위치를 되읽습니다. 실물 장치에는 접근하지 않습니다.
- `arm_sim/real_monitor.py`: 공정/카메라만 제공하며 기존 전압 수집 프로그램을 호출하지 않습니다.
- `scripts/run_real_sim.py`: 원본 출력을 `terminal.log`에 보관하고 터미널에는 시작·완료·오류를 표시합니다. `--show-warnings`로 원본 표시를 선택할 수 있습니다. 종료 신호를 자식 프로세스에 전달하고 종료 코드를 유지합니다.
- `scripts/verify_real_demo.sh`: 메시·집기·차량·받침·기구·동작 품질 검사와 유한 Isaac Sim 전체 재생. 결과는 계획 파일 해시와 묶어 보관합니다.
- `scripts/real_verification.py`: 변경된 모델·계획·검사 코드에 과거 합격 결과가 적용되지 않도록 검사합니다.

장면 기본값은 시작 대기입니다. 배속은 공정 시간을 바꾸며 모터 속도 제한을 바꾸지 않습니다. 부품을 잡기 전/후와 정밀 구간에는 기존의 서로 다른 속도·가속도 설정이 적용됩니다. 이 설정은 시뮬레이션용이며 실물 하중 검증 전에는 그대로 배포하지 않습니다.

A는 다른 재료를 집으러 돌아갈 때도 실제 팔·카메라 메시를 검사한 경로를 사용하며, 매번 안전 자세를 거치지 않습니다. 간섭 회피에 필요한 경유점은 유지하고 마지막 9번째 상차 후 안전 자세로 복귀합니다. 그리퍼 폭은 해당 부품의 접근 폭을 유지합니다. B/C는 세트 도중 대기로 돌아가지 않으며 세트 완료 후만 복귀합니다. B는 C의 조립 동안 빈손으로 안전 자세를 유지합니다.

도킹은 전진, 도킹 이탈은 직선 후진입니다. 운반로봇 150mm·지게차 200mm 이탈 후 회전하며, 포크·용기의 회전 범위를 검사합니다. 긴 이동은 전진 U자, 인접 창고 이동은 짧은 상부 U자를 사용합니다. 빈 포크의 불필요한 승강과 최종 빈 차량 복귀를 생략하고, 정지 상태의 초기 포크 높이 준비는 운반로봇 이동과 겹쳐 진행합니다. 차량 도로 예약은 중복하지 않습니다.

현재 기준 공정 시간은 598.062초입니다. 각속도·각가속도 상한은 0.55rad/s와 0.40rad/s²이며 팔 속도는 이전 설정을 유지합니다. 속도·가속도·후진 거리·A의 관절 이동량·작업 종료 자세는 `scripts/check_real_motion_quality.py`에서 변경 전 계획과 비교합니다. URDF 바퀴 간격으로 계산한 좌우 바퀴 속도 변화와 운동학적 횡방향 오차도 검사합니다. 실제 바닥·타이어의 슬립, 저크나 실물 하중을 검증한 것은 아닙니다.

팔·차량 공유 구역의 예약은 중앙 계획과 시뮬레이터 응답으로 확인합니다. ROS 토픽, 무선 Pi 통신, 실제 안전 PLC 연결은 아직 없습니다. 향후 실제 장치에서는 통신 시간 초과·위치 오차·비상 정지를 별도 현장 검증해야 합니다.
