# 통합 모니터 디자인

2026-09-14 사용자 승인: 다크 모드, 큰 시뮬레이션 전체 영상 + 그리퍼 영상 4개 + 공정 진행. 리더 진단은 별도 창.
기존 모니터의 간결한 정보 구성과 시스템 한글 글꼴을 이어간다.

- 배경 #0e1116, 패널 #181d25, 보조 패널 #202731, 경계 #354150.
- 본문 #edf1f6, 보조 글자 #a9b6c5, 선택 #9abfff.
- 수집 연결 #80d7b5, 주의 #f0c27a, 오류 #ffaaaa. 색과 상태 문구를 함께 쓴다.
- 숫자는 tabular-nums, 조작부 최소 높이 44px, 키보드 focus 2px.
- 전체 영상 1개와 팔별 영상 4개를 조회한다. 소스 중단 시 현재값을 비운다. 가상 영상과 실제 측정 대상을 구분한다.
- 작은 화면에서는 영상 그리드를 한 열로 바꾸고, 공정 패널을 영상 아래에 놓는다.

대상: web/workcell.html·css·js, web/monitor.html·css·js.

2026-09-14 변경: 공정 화면은 전체 영상 + 그리퍼 카메라 4개를 동시에 표시한다.
A/C는 RGB·깊이, B/D는 RGB·상부 시점을 전환한다. 전압·부하 진단은 `/diagnostics` 새 창으로 분리한다.
주 화면에는 공정 순서, 적재 수량, 팔별 작업, 안전 복귀 확인, 공유 구역 점유를 표시한다.
영상의 src는 수신·디코딩 성공 후 표시하며, 연결 전에는 숨겨 오류 이미지가 보이지 않게 한다.
검사기의 src 없음 경고는 이 실시간 영상 로딩 상태에 대한 의도적 예외다.

2026-09-14 공정 조작 정리: 상단에 시작 방식 2개, 배속, 공정 시작/일시정지, 초기화를 모은다. 선택한 방식은 테두리·색과 aria-pressed로 표시한다. 실행 직후와 초기화·방식 변경 후에는 시작 대기다. 전체 영상 옆에는 수량·팔별 작업·차량 이동을 표시하고, 카메라 4개는 그 아래에 둔다. 긴 작업 목록과 세부 구역·검사 수치는 접힌 상세 영역에서 조회한다. 기존 팔레트·진단 새 창·카메라 선택 기능을 유지한다.

2026-09-14 가독성 조정: 공정 화면 본문·주요 버튼 16px, 선택 버튼 15px, 상태·안내 14px, 제목 26px·패널 제목 17px. 작은 보조 표시는 최소 13px로 한다. 모바일에서도 안내 글씨를 다시 축소하지 않는다.

2026-09-14 문구 정리: 시작 방식은 “재료 상차부터 시작 / 재료 적재 상태로 시작”, 실행 버튼은 “시연 시작 / 일시정지 / 계속하기”, 초기 상태 복원은 “처음으로”로 표시한다. 상단 시계는 데이터 수신 시점이 아닌 브라우저 현재 시각이므로 “현재 시각”으로 표기한다. 영상 선택은 “그리퍼 영상 / 깊이 영상 / 상부 영상”으로 통일한다.

2026-09-14 시간 표시: `실제 경과`는 시작 대기와 일시정지를 제외한 벽시계 시간, `공정 기준`은 배속 전 경로 진행/전체 시간이다. 현재 시각과 혼용하지 않는다. 기본 배속 1배를 유지한다.
