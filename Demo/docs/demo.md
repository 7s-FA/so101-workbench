# 전체 공정 데모

팔로워 A/C의 추가 받침대는 0mm다. 원재료 18개를 9개씩 두 번 운반하고 전부 조립해 완제품 6개를 창고 두 층에 3개씩 저장한다. 실물 연결 없이 실행한다.

```bash
/path/to/Final_Arm/Demo/scripts/demo.sh --headless
```

실행 직후에는 로봇과 공정이 **시작 대기** 상태다. 웹 상단에서 **재료 상차부터 시작** 또는 **재료 적재 상태로 시작**을 선택하고 **시연 시작**을 누른다. 시작 방식을 바꾸거나 **처음으로**를 누르면 물체와 공정을 처음 상태로 되돌린 뒤 다시 시작을 기다린다. 일시정지 후에는 계속하기를 누른다. 배속은 방식 변경 시에도 유지한다.

기본 선택은 `재료 적재 상태로 시작`이다. 시작할 선택값은 `--demo-start load` 또는 `--demo-start preloaded`로 지정한다. 무인 검증에만 `--demo-autostart`를 추가해 시작 버튼을 생략할 수 있다. `--no-monitor`를 쓰는 무인 재생도 이 옵션이 필요하다.

웹 공정 화면은 http://127.0.0.1:8767/ 이고 전압·부하 화면은 `/diagnostics`다. GUI를 함께 보려면 `--headless`를 생략한다. 기존 시뮬레이터가 실행 중이면 먼저 종료한다.

## 집기와 동작

- 부품별 손가락 간격과 끝점 오프셋을 사용한다. 하우징·볼·덮개 및 완제품 전체 형상을 두 손가락 사이에 맞춘다.
- 수직으로 접근·하강·상승한다. A는 같은 부품 열을 따라 빠져나온 뒤 충분히 올려 옆 열의 볼을 넘는다. 접근 높이가 낮은 바깥쪽 슬롯에서 곧바로 옆 열을 가로지르지 않는다.
- 볼은 하우징 입구 위에서 놓고 정해진 착좌 위치까지 내려가는 보조 동작을 쓴다. 손가락을 하우징 안으로 넣지 않는다.
- 빈손 대기는 접은 자세, 부품을 든 대기는 수직 그립을 유지하는 별도 자세다. 계산용 경유점은 연속 속도로 통과하고 집기·놓기·작업 종료 경계에서는 정지한다. 이동 경로와 시간을 분리해 관절별 속도·가속도 한도를 적용한다. 가속도의 변화율(저크)과 실제 토크 한도를 검증한 경로는 아니다.
- B/D의 집기 방향은 일정하게 유지해 불필요한 회전을 줄인다. B는 작업대 왼쪽 옆면에 클램프로 고정하고, D는 오른쪽 옆면에 고정한다.

- B는 재료 3개를 연속 하차한 뒤 한 번 복귀한다. C는 한 제품을 연속 조립하고 인계한 뒤 한 번 복귀한다. 중간에 안전 자세를 거치지 않지만 집기 전후의 수직 접근·상승은 유지한다.
- D는 접은 자세에서 인계 위치 위로 바로 펼친 뒤 완제품을 지게차로 상차한다. 시작할 때 지게차 쪽 준비 위치를 먼저 거치지 않는다. 위쪽 임시 완제품 저장 용기는 제거했다.

## 공정과 배치

처음에는 빈 출하 용기 두 개를 창고 아래층·위층에 하나씩 둔다. 지게차 포크는 비어 있다.

1. **재료 적재 상태로 시작**에서는 Burger 1에 처음부터 하우징·볼·덮개를 3개씩, 총 9개 싣는다. A의 첫 상차를 생략하고 시작 1초 후 U자 경로로 조립 작업대를 향해 출발한다. A는 접은 자세로 대기한다. **재료 상차부터 시작**에서는 원재료 18개를 작업대에 두고 A가 첫 9개를 싣고 안전 복귀한 뒤 차량이 출발한다.
2. Burger 1이 조립 작업대에 도착하면 지게차가 출발해 창고 아래층의 첫 빈 용기를 회수한다. 그동안 B가 첫 세트를 준비하고 복귀하면 C가 바로 조립을 시작한다. C의 조립 중 B는 빈손 안전 자세로 대기한다. Burger 2는 지게차의 공유 통로 사용이 끝난 뒤 상차 위치로 진입하며, A의 다음 9개 상차는 B·C 작업과 병행된다.
3. 준비 용기는 두 세트용 슬롯을 번갈아 쓴다. 다음 하차는 C의 조립·인계 완료 후 시작하므로, 아직 사용 중인 슬롯을 덮어쓰지 않는다.
4. 첫 빈 용기가 지게차의 상차 위치에 준비되고 C가 완제품을 인계하고 복귀하면 D가 지게차에 직접 상차한다. 이때 B의 다음 세트 하차와 D의 상차가 병행된다. C는 B/D의 안전 복귀 응답을 받은 뒤 다음 제품 조립에 진입한다.
5. 지게차는 첫 완제품 인계 전에 상차 높이를 맞춘다. 완제품 3개 상차와 D의 복귀가 끝나면 U자 경로로 위쪽 중앙 창고에 접근하고, 아래쪽 입구로 진입해 아래층에 적재한다.
6. 포크를 빼고 위층에 처음부터 있던 두 번째 빈 용기를 회수해 돌아온다. 첫 출하 용기와 제품은 아래층에 그대로 남는다.
7. Burger 2의 나머지 9개도 B→C→D로 모두 처리한다. 지게차가 두 번째 완제품 3개를 위층에 적재하고 복귀하면 공정이 완료된다. 원재료나 용기를 중간에 새로 생성하지 않는다.

짙은 회색 바닥은 가로 3m × 세로 2m다. 목재 작업대 높이는 임시 230mm이며, 로봇팔에는 기존 4mm 고정판만 사용한다. 원재료 용기는 A 양쪽에 각각 3×3 정사각 배열로 놓인다. 사전 적재 방식은 왼쪽의 첫 9개를 Burger 1에 두고 오른쪽 용기에 나머지 9개를 둔다. 재료 상차부터 시작 방식은 양쪽 용기에 9개씩 둔다. 바깥쪽부터 캡·하우징·볼 순서로 좌우를 대칭 배치해 같은 행 높이에서도 수직 집기가 가능하다. 부품 중심 간격 63mm는 50mm 부품 사이에 13mm 여유를 준다. Burger 운반면은 200×200mm이고 3×3칸이다.

조립 준비·조립·완제품 인계는 690×415mm 상판을 공유한다. B·D 고정판은 아래쪽 두 꼭짓점과 정확히 맞닿는다. B 클램프는 왼쪽 변, D 클램프는 오른쪽 변에 고정하며, 상판 오른쪽은 맵 경계에서 130mm 안쪽이다. 폭을 늘릴 때 D를 기준점으로 두고 B·C 작업 구역과 하차 도킹 위치를 함께 왼쪽으로 조정했다. 준비 용기는 C를 기준으로 왼쪽·위쪽 각각 20mm, D 앞 인계 받침은 위쪽으로 20mm 더 떨어뜨렸다. 고정판과 용기의 평면상 간격은 C 옆 28mm, D 앞 29mm이며, 동작 중 간격은 전체 경로 형상 검사로 별도 확인한다. 조립 작업대 다리는 앞·뒤 가장자리에서 중심까지 80mm 들어가 있어 하부 클램프를 피한다. 화면과 간섭 검사는 같은 다리 좌표를 사용한다.

장면의 글씨와 흰색 이름표는 숨기며 진행 정보는 웹 패널에 표시한다. 재료 상차·하차, 완제품 상차, 창고의 도킹 위치 뒤에는 180×180×8mm 수직 패널을 둔다. 남쪽 면에 70mm ArUco 마커(DICT_4X4_50, ID 10–13)를 배치하고, 포크 끝보다 뒤에 벽을 두어 진입 공간을 비운다. Burger는 후방 카메라를 사용하는 배치이며, 실물 카메라 높이·시야에 따른 마커 위치 보정은 필요하다. 패널은 경로·형상 검사에 포함되지만 마커 인식 기반 자동 도킹 제어는 이번 배치에 포함하지 않는다. 마커 원본과 패턴은 `assets/factory/aruco/`에 있다.

Burger 운반면 높이는 210mm, 지게차 포크 상면은 차체 원점 기준 24mm다(시뮬레이션 바닥 기준 25mm). 포크 아래는 바닥에서 7mm 떨어진다. 창고 선반은 25/230mm, 마스트 상단은 293mm다. 이 치수는 시뮬레이션 배치용이며 실측 도면이 아니다. LiDAR는 기본 위치를 유지하고 일부 가림을 허용한다.

## 속도와 화면

전체 6개를 처리하는 공정 기준 시간은 사전 적재 방식 **591.50초(9분 52초)**, 재료 상차부터 시작 방식 **684.85초(11분 25초)**다. 첫 9개 상차를 생략하는 사전 적재 방식이 10분 목표의 기준이다. 기본 배속은 1배다. `실제 경과`는 시작 대기·일시정지를 제외한 실제 시간이고, `공정 기준`은 배속 적용 전 경로의 진행 시간/전체 시간이다. 렌더링 지연은 제한된 범위에서 보정하며 안전 게이트를 건너뛰지 않는다. 웹 상단의 `시연 속도`에서 0.25–16배를 선택한다. 시작 배속은 `--demo-speed 4`처럼 지정할 수 있다. `실제 시연 속도`는 렌더링·검사 시간을 포함한 진행 비율이다. `demo.sh`는 실시간 형상 검사를 기본으로 끈다. 관절 변화 제한, 안전 복귀 응답, 공유 통로 예약과 도착 확인은 유지한다. 실행 중 메시 간섭 검사도 필요하면 `--runtime-geometry`를 추가한다. 실물 모터 설정은 변경하지 않는다.

카메라 렌더링·웹 영상 갱신 목표는 실제 시간 기준 15fps이며 `--camera-fps 15`로 지정할 수 있다. 렌더링·전송이 느리면 실제 프레임은 낮아질 수 있다. 전체 영상과 그리퍼 영상 4개를 함께 표시한다. A/C는 RGB·깊이, B/D는 그리퍼 RGB·상부 영상을 선택할 수 있다. 작업 진행은 조립·저장 각각 6개를 목표로 표시하고 공유 주행 통로의 사용 차량·대기 차량도 보여준다. 실물 미연결 상태의 전압·부하는 가상 측정값으로 채우지 않는다.

### 집기 전후 속도

`config/demo_motion.json`에서 구간별 시험 한도를 지정한다. 변경 후 다시 실행하면 두 시작 방식 모두 다시 계산한다. 단위는 관절 회전 기준이며 이동 거리나 작업 성공률을 뜻하지 않는다.

| 구간 | 최대 관절 속도(rad/s) | 최대 관절 가속도(rad/s²) |
|---|---:|---:|
| 빈손 이동·복귀 | 2.4 | 6.0 |
| 부품·완제품 운반 | 1.8 | 4.0 |
| 최종 수직 접근·집기 직후 상승·놓기 직후 후퇴 | 1.0 | 3.0 |
| 그리퍼 개폐 | 1.0 | 3.0 |

그리퍼 한도는 빈손 구간에서도 유지한다. 소유권이 실제 데모 단계에서 팔로 넘어간 뒤부터 운반 한도를 쓰며, 놓은 뒤에는 빈손 한도로 바뀐다. 구간 경계에서 정지하므로 설정 전환으로 속도가 튀지 않는다. B/D의 원호 반경은 160–200mm 범위에서 정해 불필요한 접힘과 이웃 팔 쪽으로 벌어지는 동작을 함께 제한하고, 원호를 직선 조각으로 나눌 때 발생하던 반복적인 팔꿈치 굽힘도 제거했다. 차량 속도 상한은 0.20m/s로 유지하고 U자 통로의 하단을 y=-0.35m로 단축했다.

이 값은 **실물 배포를 승인한 모터 설정이 아니라 공정 설계용 시험값**이다. 실제 10분 이내 완료 여부에는 인식·도킹·무선 통신·실제 파지 확인과 재시도 시간이 추가된다. 현재 시뮬레이션은 보조 고정과 관절 상태 적용을 사용하므로, 실물 적재 조건에서 위치 오차·전류·온도를 측정한 뒤 운반 속도와 가속도를 확정해야 한다. 제조사의 무부하 회전수만으로 적재 상태의 속도를 보장하지 않는다.

## 검사와 작업 순서 제어

- 기본 데모에서도 관절 변화 제한, 시뮬레이터 관절·물체·용기 위치 확인을 유지한다.
- 공유 작업 구역은 의존 관계와 점유권으로 제어하며, 팔이 안전 자세로 복귀했다는 응답이 있어야 넘겨준다. 오류 시에는 공정을 정지한다.
- 차량은 공유 U자 통로를 한 대씩 예약한다. 도착 위치(5mm)와 방향(0.02rad)을 시뮬레이터에서 읽어 확인해야 다음 이동을 허용한다.
- 시작 전 관절 범위와 차량 경로 검사는 유지한다. 전체 팔·부품 간섭은 별도 오프라인 검사로 검증한다.
- `--runtime-geometry`를 켜면 실행 중 모든 팔 조합의 URDF 형상에 20mm 간격 기준을 적용한다. 대기 중인 팔도 포함한다. 그리퍼·들고 있는 부품의 삼각형 메시를 다른 팔·부품·작업대·클램프·용기·지게차·선반과 대조한다. 관절 변화 최대 0.01rad, 차량 이동 최대 5mm 간격으로 보간 검사한다.
- 기본 꺼짐 상태에서는 이 실행 중 형상·차량 간격 검사를 하지 않으며 웹에도 꺼짐으로 표시한다. `factory.sh --demo`를 직접 사용하는 검증 실행은 형상 검사가 기본 켜짐이다.

ROS 상태 출력은 `scripts/demo_ros_status.sh`로 실행한다. `/factory_demo/workcell/state`와 팔별 상태 토픽을 발행한다. 이 출력만으로 실물 로봇을 제어하거나 진입을 허가하는 구조는 아니다.

이는 보조 고정을 사용하는 기하 검증 데모다. 마찰·힘·조립 공차에 의한 실물 성공을 입증하지 않는다. 파란 그리퍼의 정확한 실물 CAD와 카메라·케이블 외형이 확보되면 그 형상으로 다시 검사해야 한다.
