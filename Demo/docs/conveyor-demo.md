# 최종 3×2m 데모 배치에 최신 하드웨어 반영

2026-09-15. 기준은 `scripts/demo.sh` → `arm_sim/factory_demo.py:demo_layout`의 최종 9월 14일 실행본이다. `outputs/final_demo_reference/`는 현 최종 코드를 120스텝만 실행해 새로 캡처한 기준 화면이며 전체 공정 재검증 결과는 아니다. 중간 `all18_runtime` 이미지를 기준으로 쓰지 않는다.

**기존 배치의 모습과 팔 방향을 유지하면서 최신 그리퍼·카메라·개조 지게차·낮은 받침·새 부품을 반영하고, 컨베이어만 제외했다. 현재 수정 장면은 배치 미리보기다. 기존 데모의 전체 공정 제어·궤적을 최신 하드웨어에 이식하는 작업은 미완료이며 `demo.sh` 자체는 기존 검증본을 유지한다.**

## 구성

| 항목 | 현재 배치 |
|---|---|
| 맵 | 가로 3,000×세로 2,000mm, 짙은 회색 |
| 왼쪽 재료대 | 구매한 400×400mm 한 장, A와 부품 9개 |
| 오른쪽 조립대 | 구매한 900×400mm 한 장, B/C/D |
| 예비 상판 | 400×400mm 한 장과 600×400mm 한 장, 사용하지 않음 |
| 팔 | A/C SO-101, B/D OMX |
| 카메라 | A/C D435와 측면 마운트, 독립 상부 카메라 한 대 |
| 준비 지그 | 고정식 3종 한 세트, B/C 상호 배제 후 인계 |
| 초기 재료 | A 앞 Burger 1에 9개, 재료대 9개, Burger 2는 빈 차 |
| 출하 | D 앞 별도 낮은 받침, 용기는 작업대에 내려놓고 적재 |
| 지게차 | 개조 Waffle, 가이드·나사 승강·프레임·낮은 포크 유지 |
| 창고 | 위쪽 중앙 두 개, 빈 용기 각 한 개는 위층에서 시작 |
| 통로 | 기존처럼 아래쪽 공유 U자 통로, 차량별 배타 점유 필요 |

상판 높이 230mm, 두께 30mm·다리는 임시 치수다. 팔로워 상승 받침과 B/D 추가 고정판은 없다. OMX 원래 베이스 바닥을 상판에 직접 놓고, 원래 베이스의 13mm 높이 가장자리를 두 변의 클램프로 잡는다. 출하 받침 130mm, 창고 35/130mm, 최대 포크 높이 150mm를 유지한다. 낮은 받침과 창고는 구매 상판과 별도 제작 구조물이다. 지게차 도킹 마커는 제외하고 Burger 마커만 남긴다.

## 위치와 원본 대비 변경

좌표는 m, 위쪽이 +Y다. 두 상판 앞선 Y=0.400, 재료대 중심 `[-0.805462,0.600]`, 조립대 중심 `[0.910,0.600]`이다.

- A `[-0.950,0.600]`, 아래쪽(-90°) 방향. 사각 상판 왼쪽 변에서 고정하고 오른쪽 재료를 아래 차량에 싣는다. 실제 베이스 방향에 맞춰 클램프 두 개의 위치도 조정했다. 중심 위치만 이동한 수평 회전 팔로 바꾸지 않는다.
- B `[0.520,0.475]` 0°, C `[0.910,0.777635]` -90°, D `[1.300,0.475]` 180°. D의 X=1.300은 최종 원본을 유지한다. 900mm 상판에 맞춰 B/C를 왼쪽으로 옮기고 B/D는 앞쪽 꼭짓점에 고정한다.
- 원재료 지그 중심 `[-0.765462,0.510]`, 간격 75mm의 3×3 정렬. 준비 지그 X=0.580/0.655/0.730, Y=0.650.
- 조립 `[0.925,0.540]`, 인계 `[1.100,0.490]`, 출하 받침 `[1.190,0.330]`. 지게차가 우측 경계 안에서 회전하도록 출하 받침만 30mm 안쪽으로 조정했다.
- 상부 마운트 `[1.080,0.740]`. 창고 `[-0.390,0.790]`, `[-0.010,0.790]`. 차량 2는 `[-1.280,0.100]`에서 대기한다.
- Burger 도킹 Y=0.230. 32mm 적재판 오프셋을 포함해 상판 앞에 20mm를 비운다.

최종 원본의 순서는 첫 차량 출발 → B 세 부품 하차 → C 조립/인계 → D 직접 상차이며, B/D 병행과 C 작업 구역 배타 점유를 이식 기준으로 삼는다. 새 장면에서도 지게차는 빈 포크, 출하 받침은 빈 상태로 시작한다. 빈 용기는 창고에서 회수해야 한다. 공유 통로는 차량 한 대씩 점유해야 하며, 표시선만으로 충돌 방지가 구현되었다고 보지 않는다.

## 카메라와 모델

A·C에는 XLeRobot `SO101_soft_fin.stl`에서 분리한 실제 고정부·가동부·TPU 손가락 형상과 RealSense D435 제조사 CAD/공식 출력 마운트를 사용한다. 개폐 모터 고정부의 로컬 −X 옆면에 마운트를 직접 붙이고, 사용자가 새로 뚫었다고 확인한 나사 다섯 개를 표시한다. 좌표는 사진 기반 추정이며 실측 천공 도면이 아니다.

마운트 기준점은 그리퍼 로컬 `[-35.32,0,-17.4]mm`다. 이전 사진과 비교한 측면 틈은 약 4.65mm, 전체 메시 최단 간격은 약 5.34mm다. 손목 회전 약 −87.21°로 개폐 방향을 수평으로 맞췄다. 카메라 뒤 0.5mm 와셔는 임시 가정이다. TPU 변형·마찰 파지·실제 광학 보정은 검증하지 않았다.

상부 카메라는 공식 Bottom/Middle/Top 출력물과 32×32 카메라 메시를 조립한 독립 마운트 한 대다. A·C의 D435 영상은 명목 렌즈 위치의 가상 색상 영상이며 실측 깊이 측정 결과가 아니다. `gripper_arm_a/b/c/d.png`는 각 그리퍼를 살펴보기 위한 검사 시점 영상이다.

## 검증과 실행

- 19개 단위 검사: 팔 배정, 상판 치수·지지·모서리·수량·도킹 여유 등을 확인.
- `rest_check.json`: 대기 자세의 자기/상판/팔 간 접촉 검사.
- `hardware_check.json`: 최신 그리퍼·D435·마운트·클램프·지그와 재료 18개의 대기 간격. SO 개폐 81표본씩, 승강 57표본. 실물 강성·부하·정확한 체결 치수는 미검증.
- `reach_check.json`: 78개 위치 IK. 수직 파지 자세·경로·토크 검증은 제외.
- `overhead_check.json`: 독립 상부 카메라의 지지와 대기 간격.
- `floorplan_check.json`: Waffle STL·공식 R200 충돌 상자·개조 승강부·운반 용기의 평면 외접 사각형으로 실제 예정된 90° 회전 세 곳을 1° 간격 검사. 표본 사이 최대 변위 약 3.6mm도 차감한다. 최소 여유 약 57mm. 도킹 삽입·직선 주행 전 구간·동시 교통 제어 검증은 제외.
- `report.json`: 실제 USD에서 팔 네 대, 컨베이어 없음, 재료 9+9개, 창고의 빈 용기 두 개 확인.

결과는 `outputs/conveyor_preview_latest/`에 저장한다. 전체 공정 성공과 물리적 파지 성공은 아직 검증하지 않았다. 기존 데모 시간/합격 보고서를 최신 하드웨어의 성능으로 사용하지 않는다.

이미지와 장면을 생성하고 자동 종료하며 웹서버·실물 모터는 시작하지 않는다.

cd /path/to/Final_Arm
