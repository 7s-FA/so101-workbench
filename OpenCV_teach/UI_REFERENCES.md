색상·글꼴·위젯 스타일의 원본은 `teaching_ui.py`입니다.

   - 개조 SO-101의 3D 미리보기를 오른쪽에 배치하고 기존 로봇 제어 기능과 구분합니다.

## 구현·검증 범위

- 외부 코드·이미지·브랜드 자산을 복사하지 않고 기존 Tkinter 위젯으로 구현했습니다.
- `impeccable`로 기존 흐름과 가독성을 점검하고, `ui-ux-pro-max`의 데이터 밀도 지침을 참고했습니다.
- 한국어, 스텝별 관절값 편집, 저장 형식과 기존 모터 제어 로직을 유지했습니다.
- J1~J6 축 번호와 설정된 제어 주파수·목표 변화율을 표시합니다. 이 설정값은 측정값이 아닙니다.
- 데모로 실제 창 렌더링, 확대 글꼴·좁은 창, 편집·저장·불러오기·재생을 확인했습니다.
- 실물 로봇 구동 검증이나 산업용 안전 인증을 의미하지 않습니다.


## 현재 화면 구성 (2026-09-22)

스타일 원본은 `teaching_ui.py`입니다. `app_navigation.py`의 페이지 전환으로 단일 Tk 창을 유지합니다.

- 상단: **에피소드 / 실물 조정 / 카메라 / 장비 설정**. 하위 작업에는 **← 뒤로 / 에피소드로**가 있습니다.
- 로봇 상태와 하단 연결·자세 유지·정지 조작부는 화면 전환에도 유지됩니다.
- 에피소드: 관절표·스텝 목록·3D 미리보기. 실물 조정: 카메라·도킹 기준·모터 틱 슬라이더.
- 초기 설정: **로봇 연결·영점 / 카메라 보정 / 지그·집기 목표 / 고급 · 집게 끝**. 모터 영점은 SO-101 캘리브레이션 화면으로 통합했습니다. 중복 모델 영점 화면은 제거했습니다.
- 중복 도구 모음과 이전 마커 목표 전환 버튼을 제거했습니다. 표준 버튼의 테두리·배경·눌림·비활성 상태를 강화했습니다.
- 저장·취소와 보정 단계 버튼은 페이지 하단에 고정합니다. 긴 폼은 안에서 스크롤합니다. 파일과 선택 목록도 앱 내부 방식입니다.
- 도움말은 장비 설정 또는 F1입니다. HTML 설명서와 공식 영상은 브라우저를 사용합니다.

## OpenCV 검출과 선택 목록

마커 사전·ID·PNG 생성 대신 지그 실측 크기·설치 높이·도킹 방향·검출 영역을 편집합니다. 직사각형과 도넛형을 선택하며 도넛형은 STL 내부 구멍과 외곽을 참고합니다.

- 초록은 외곽을 확인한 후보, 주황은 경계가 약하거나 가려진 추정 후보입니다. 후보가 여러 개면 중심·각도를 비웁니다.
- 픽셀 중심·영상 각도와 로봇 기준 mm·각도를 구분합니다. 제품명은 사용자가 선택한 이름이며 자동 분류 결과가 아닙니다.
- `app_choices.py`의 Frame 목록은 Test_IL의 앱 내부 선택 방식을 참고했습니다. 파일·폴더도 현재 창 안에서 선택하며 OS 선택창을 띄우지 않습니다.
- 팔로워 단독 모드는 리더 열·따라가기·동기화를 숨깁니다. 일반 자세 저장과 지그 기준 목표 반영을 별도 버튼으로 제공합니다.

## 2026-09-22 온도 지속시간 표시

현재 고온 대기 상태는 메인 상태줄과 진단창에 ‘온도 높음 2.0/5초’로 표시합니다. 진단창은 고온 대기를 황색, 중단 오류를 적색으로 구분합니다. 그래프 선은 즉시 정지선이 아닌 ‘고온 기준’으로 표시하며, 제한값 패널에 연속 5초·감시 공백 1.5초·즉시 차단 조건을 설명합니다. 설명서의 15번 이미지는 모의 데이터로 확인한 화면입니다.

## 상태 모니터링 버튼

**장비 설정 → 로봇 연결·영점 → 모터 상태 · 전압·온도**에서 같은 창의 진단 화면으로 이동합니다. **← 뒤로**는 화면만 돌아가며 연결·측정은 유지합니다. 연결 전 대기, 연결 중 갱신, 고온 대기, 종료 후 마지막 값을 구분합니다.

1440×900·1080×760 화면과 단일 창 전환, 파일 읽기 미리보기, 하단 버튼을 확인했습니다. 자료는 `verification/20260922_single_window/`에 있습니다. 저장 자세·모의 값으로 검증했으며 실제 모터를 움직이지 않았습니다.

## 마우스로 감지 범위 지정하기

**카메라 → 감지 확인 → 감지 범위 직접 지정**을 누르고 영상에서 마우스로 사각형을 끌어 놓습니다. 지그가 아직 검출되지 않아도 지정할 수 있습니다. 파란 테두리 안에서 선택한 지그를 찾고, 범위는 해당 지그 설정에 저장됩니다. **전체 범위로**를 누르면 제한을 해제합니다. 여러 부품이 같은 지그를 공유하면 같은 범위를 사용합니다.

영상 바깥 여백은 제외하며 반대 방향으로 끌어도 됩니다. 너무 작은 범위는 저장하지 않습니다. 지그가 도착할 위치와 회전했을 때의 외곽이 모두 들어오도록 지정하세요. 범위를 바꾸면 이전 지그 기준을 해제하므로 다시 측정합니다. 이전 ‘현재 지그 주변으로 범위 줄이기’ 버튼은 직접 지정으로 교체했습니다.

스텝 관절값 편집은 **왼쪽 편집 / 오른쪽 시뮬**로 표시합니다. 편집 중인 스텝 이름은 상단에 남으며 수치 변경은 시뮬에 즉시 반영됩니다. 적용 전에는 원본 스텝이 바뀌지 않습니다. 현재 작업 메뉴는 **청록색 배경과 ● 표시**로 구분하며, 스텝 편집 중에는 에피소드 메뉴가 선택됩니다.

## 스텝 목록과 편집

- 스텝을 마우스로 잡아 원하는 행으로 끌어 놓아 순서를 바꿉니다. 행이 청록색으로 표시되며, 목록 위·아래 가장자리에서는 스크롤됩니다. Alt+↑/↓도 사용할 수 있습니다. 시작·종료 안전 자세는 처음과 끝에 유지합니다.
- **스텝 실행**은 조작 버튼 맨 위에 길게, **안전 자세 추가 / 스텝 삭제**는 같은 줄에 둡니다. 순서 올리기·내리기 버튼은 제거했습니다. 이미 안전 자세가 있으면 해당 스텝을 선택하며 값을 덮어쓰지 않습니다.
- 스텝 설정의 **집게만 조절** 선택을 제거했습니다. 이전 파일의 집게 단계는 읽기와 실행을 계속 지원합니다.
- 지그 보정 스텝의 관절값 편집에서는 자동 계산되는 몸체 J1~J5의 입력·슬라이더·±를 비활성화합니다. 집게 J6는 편집할 수 있습니다. 같은 목표의 열림/닫힘 값을 공유하는 단계도 함께 갱신하고 경로는 실행 시 다시 계산합니다.
- 고정 스텝은 6개 관절을 모두 편집합니다. 저장 전 시뮬과 스텝 이름을 함께 확인할 수 있습니다.

**실물 조정**은 실제 팔을 조금씩 움직여 위치를 찾을 때, **관절값 편집**은 시뮬에서 먼저 자세를 확인할 때 사용합니다. 관절값 편집만으로 실제 팔은 움직이지 않습니다.

- 여러 지그: 장비 설정의 지그 등록·선택에서 새 지그·복사·편집. 에피소드 상단에 사용할 지그 목록. 부품별 고급 폼은 일반 설정 화면에서 숨기며 기존 파일은 읽기 호환 유지. 저장·사용 버튼은 폼 아래에 고정.

## 2026-09-22 다중 지그·실행 모드

- 최종 사용자 결정: 스텝 설정은 기존 3D 미리보기 영역을 대체한다. 왼쪽 에피소드·스텝 목록은 그대로 두고 시뮬 보기 버튼으로 복귀한다. 옆 작은 패널·전체 페이지 방식은 사용하지 않는다.
- 스텝마다 지그를 고르고 카메라의 범위를 설정할 지그 목록에서 해당 지그의 ROI만 편집한다.
- 상단 장비 모니터링을 바로 열 수 있다. 팔로워 단독 연결은 토크 꺼짐이며 명시적인 자세 유지·토크 해제 버튼을 사용한다.
- 자동 실행 측정 성공 후 에피소드 화면으로 복귀한다. 측정 실패는 감지 화면에 이유를 남긴다.

## STL 지그 관리

지그 등록 탭은 왼쪽 설정과 오른쪽 3D를 유지한다. 가상 배치는 제거하고 확정된 카메라 위치가 있을 때만 지그를 표시한다. STL 외곽 윗면에서 검출면 높이를 계산한다. 직사각형·도넛형을 선택하며 도넛형은 STL 구멍 구조를 참고한다. 카메라 각도 가져오기는 측정 화면으로 이동하고 완료·실패·취소 시 관리 화면으로 복귀한다. 성공 시 도킹 기준 방향만 입력하고 지그 저장으로 확정한다. 작은 화면의 저장·티칭 버튼은 고정 하단에 둔다.
