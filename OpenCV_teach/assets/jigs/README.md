# 흰색 테스트용 하위 지그

사용자 제공 `carrier_6jigs_220x148_M3_flat_lightweight.stl`의 바이너리 메시(12,228개 삼각형)를 읽어 확인한 값입니다.
STL 형식은 단위를 저장하지 않으므로 파일명과 사용 목적에 따라 모델 단위를 mm로 해석합니다.

- 외곽 범위: X −110~110, Y −74~74 → **220×148mm**
- 전체 높이: Z 0~6mm
- 가장 바깥 테두리: Z 0~4.8mm
- 일부 고정부: Z 5.1~6mm
- 사진의 구성: 3열×2행, 개별 부품 지그를 얹는 하위 프레임
- 테스트 출력물 색상: 흰색(사용자 확인)

인식 좌표의 원점은 하위 프레임 외곽 직사각형의 중심이며, +X는 긴 변 중 설정한 도킹 방향입니다.
GUI 초기 치수는 STL 기준 220×148mm입니다. 실제 출력 치수는 따로 확인하세요.
**외곽 테두리 Z = 로봇 베이스 기준 지그 바닥 설치 높이 + 4.8mm**입니다.
전체 모델 높이 6mm를 외곽 테두리 높이로 사용하지 않습니다.
설치 높이는 STL에서 알 수 없으므로 GUI에서 직접 입력해야 합니다.

사진의 픽셀 외곽 점검은 카메라 보정이나 실물 위치 정확도 검증을 대신하지 않습니다.
개별 칸의 TCP 위치·방향·집기 높이는 실제 장착된 부품별 지그를 기준으로 등록합니다.
