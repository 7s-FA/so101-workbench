# 승인된 화면 및 동작

2026-09-17 승인: 어두운 작업용 화면, 쉬운 한국어 UI (2026-09-17 변경), 큰 Isaac 영상 왼쪽·그리퍼/고정 카메라 오른쪽. 하단 에피소드 선택/재생은 축소하고 드롭다운 목록을 사용한다. 원본 시간으로 재생하며 배속 기능은 없다. 폰트 축소로 공간을 확보하지 않는다.

토큰과 실제 레이아웃 원본은 `web/style.css`다. 이전 대화의 SO-101 Imitation Learning compact UI를 바탕으로 한다. 시뮬을 CSS 도형으로 대체하지 않으며 실제 Isaac 렌더가 준비되지 않은 경우 명확히 빈 상태를 표시한다.

범위: SO-101-L→SO-101-F 시연, RGB 두 대, 실물 작업 시연. 시뮬 장면은 작업대와 팔만 표시하며 물체·지그는 생략. 저장은 순차 ID, 임시 폐기는 ID 미소비. 팔 복귀와 부품 재배치를 분리한다. 실제 하드웨어 명령은 명시적인 조작·재실행에만 발생한다.

1차: 수집·확인·실물 재실행. 저장 시 LeRobot 표준 데이터셋 생성. 2026-09-18: 사용자 지정 작업 분류·ACT 학습 설정·체크포인트 선택 실물 실행을 추가. 학습 탭은 영상 영역을 축소하여 설정이 잘 보이게 하고 실물 실행 탭은 기존 큰 영상을 유지한다. 미구현 기능에 성공 상태나 허위 샘플 진행률을 표시하지 않는다.

표시 용어: 에피소드→작업 기록, 리더→조작용 팔, 팔로워→작업용 팔. 저장 데이터와 API 식별자는 기존 값을 유지한다.

조작은 자료의 절대 관절값 매핑을 사용한다. 시작 시 리더 자세로 서서히 맞추고, 준비 중 리더 이동은 재시작하도록 안내한다. 상대 시작 오프셋을 더하지 않는다.

2026-09-18: 작업 분류는 실제 작업 폴더다. 녹화 탭의 폴더 관리로 학습 탭의 만들기·이름 변경에 진입하고 저장 경로를 표시한다. 기록의 폴더 변경은 실제 이동이며 자료의 LeRobot 데이터셋·ACT 학습 방식은 유지한다.


## 학습 중 수집과 이어 학습 (2026-09-18)

학습을 시작한 뒤 리더암 조작·녹화·저장을 계속 허용한다. 학습은 시작 시점의 불변 데이터 버전과 에피소드 번호를 사용하며 이후 저장한 기록은 다음 이어 학습에서만 반영한다. 이어 학습 UI는 저장 모델·추가 학습 횟수·기존/현재 폴더 데이터 선택을 제공한다. 새로운 학습 폴더에 저장하고 원본 체크포인트를 보존한다. LeRobot의 가중치·옵티마이저·난수·학습 횟수 복원을 사용하며 기존 전처리/후처리 정규화 통계를 유지한다. 관절 보정·카메라 크기·기록 주기 호환성을 확인한다.

중단 요청은 파일 신호로 전달한다. 학습 담당 프로세스가 다음 계산 완료 후 체크포인트 전체를 저장하고 완료 표시를 쓴 뒤 종료한다. 웹은 저장 대기 상태를 표시하며 학습 담당 프로세스와 같은 job.json을 동시에 수정하지 않는다. 모터 제어 설정과 카메라 오류 감지는 바꾸지 않는다.


## 최근 모델 보관 (2026-09-18)

새 학습과 이어 학습의 **이번 학습은 최근 모델 1개만 보관**은 기본으로 켜져 있습니다. 중간 저장 간격마다 새 모델·전처리/후처리·옵티마이저·난수·학습 횟수를 모두 저장한 뒤 이번 학습 폴더의 이전 중간 모델을 삭제합니다. 저장 중에는 이전 모델을 유지하여 일시적으로 두 개의 공간이 필요하며, 실패한 저장으로 이전 모델을 지우지 않습니다. 학습 중단 시 저장에도 같은 규칙을 적용합니다. 체크를 끄면 중간 모델을 모두 보관합니다. 이어 학습의 원본 모델이 들어 있는 이전 학습 폴더, 다른 작업의 모델, 에피소드는 삭제하지 않습니다. 기존 실행 중인 프로세스의 보관 설정은 바꾸지 않으며 다음 실행에서 반영됩니다.


## 모델 개별 삭제 (2026-09-18)

**학습한 동작 실행 → 모델 선택 → 선택한 모델 삭제**에서 이름과 학습 횟수를 확인한 뒤 **삭제**를 눌러야 삭제합니다. 취소 또는 Esc로 닫으면 변경하지 않습니다. 선택한 체크포인트의 모델과 이어 학습 상태를 영구 삭제합니다. 같은 학습의 다른 모델이 남아 있으면 공통 학습 기록을 유지하고, 마지막 모델을 삭제하면 해당 학습 폴더의 설정·진행 기록·로그도 함께 삭제합니다. 원본 에피소드와 다른 학습 폴더는 유지합니다. 마지막 모델도 사용 중이 아니면 삭제할 수 있습니다. 학습 중인 작업의 모델과 이어 학습의 원본 모델, 실행 준비/실행 중인 모델은 서버에서도 삭제를 거부합니다. 실행 준비된 모델은 **멈추고 자세 유지**로 해제한 뒤 삭제합니다.

## 모델별 실행 설정 (2026-09-18)

학습한 동작 실행 탭의 기존 디자인을 유지한다. 실행 방식·실행 길이·연결 필터·잔떨림 필터를 기본 영역에, 계산 시점·ACT 평균 가중치·그리퍼 필터를 접힌 고급 영역에 배치한다. 기존 방식이 기본이며 저장한 모델의 원래 실행 길이로 복원할 수 있다. 설정을 바꾼 뒤 모델 불러오기를 다시 해야 실행 가능하다. 모터가 동작하는 중에는 변경하지 않는다. 새 예측 계산과 저장된 동작 꺼내기를 구분하여 표시하고 설정·실행 지표를 결과에 기록한다. 설정 저장은 모델 가중치나 에피소드를 변경하지 않는다.

## 탭별 조작 흐름 (2026-09-20)

상단에 작업용 팔·조작용 팔·모터 힘·카메라 수신 상태와 다음 조작을 표시한다. 모터 힘 끄기는 황색, 정지·삭제는 기존 적색을 유지한다. 연결, 힘 활성화, 정지 후 힘 유지, 힘 해제, 연결 종료를 각각 구분한다. 힘 해제는 기존 검증 명령으로 모든 모터 상태를 확인하고 읽기 전용으로 돌아오며, 실패 시 상태 미확인과 재시도 경로를 보존한다.

동작 기록은 탭 안의 폴더 관리·연속 녹화·실제 녹화 상태를 제공한다. 기록 확인은 영상·시뮬과 실물 실행을 명시한다. 학습과 모델 실행은 비활성 버튼의 이유를 주변에 표시하고, 모델 불러오기와 실물에서 실행을 구분한다. 짧은 화면에서도 녹화 핵심 버튼이 보이도록 영상 높이와 간격을 줄인다. 키보드 조작과 기존 상단 오류 안내를 유지한다.

2026-09-20: 완료된 학습 파일 저장 안내는 숨기고 생성 중·오류 안내는 유지한다. 관절 각도 보기는 테두리·배경·펼침 화살표와 열림 상태를 갖는 버튼이다. 단축키는 모든 탭에서 왼쪽 메뉴 아래 항상 표시한다.

모든 조작 버튼은 기본 상태에서도 배경과 테두리를 표시한다. 주요 실행·정지·모터 힘 해제의 색 구분은 유지하고, 비활성 버튼은 흐린 색으로 구분한다. 학습 파일 갱신은 하단 관절 각도 보기 옆에 배치한다. 별도 상태 줄은 생성 중이나 오류 등 안내가 있을 때만 표시한다.

버튼 사이 기본 간격은 16px이며 상단·하단·대화창에서도 동일하게 적용한다. 조작과 저장처럼 역할이 다른 버튼 묶음은 최소 24px 간격을 둔다. 좁은 창에서는 버튼 크기를 줄이지 않고 줄바꿈한다.

하단은 상태 문구를 왼쪽, 보조 버튼을 오른쪽에 정렬한다. 관절 각도 보기·학습 파일 갱신은 같은 너비와 글자 크기, 32px 간격을 사용하고 작업 패널 안쪽 여백에 맞춘다. 좁은 창에서는 버튼 묶음을 다음 줄로 내려 정렬한다.

학습 기록 선택은 앱 내부 목록으로 표시한다. 긴 이름은 목록 안에서 줄바꿈하고 생성 날짜는 별도 줄에 둔다. 목록 폭은 오른쪽 패널에 맞추며 화면의 남은 공간에 따라 위·아래로 펼친다. 자동 갱신 중 선택·스크롤·키보드 포커스를 보존한다.

2026-09-20: 모든 선택창은 학습 기록과 같은 앱 내부 목록을 사용한다. 작업 폴더·기록·모델·실행 설정·장치 선택을 공통 컴포넌트로 표시하고, 기존 선택 값·변경 명령·비활성 조건은 유지한다. 긴 이름은 목록에서 줄바꿈하며 선택 표식, 방향키·Enter·Esc·Tab 이동과 목록 내부 스크롤을 지원한다. 대화창에서도 목록이 잘리지 않도록 표시한다.

2026-09-22: 모델 실행은 자료 기준으로 목표를 직접 전달한다. 추가 속도·가속도 제한 입력을 제거하고 실행 방식을 ‘자료 기본 방식’으로 표시한다. 선택형 동작 연결·잔떨림 필터, 초기 자세 이동, 관절 범위와 상태 감시는 유지한다.

2026-09-22: 구동 중 고온 지속시간을 기존 상단 알림에 표시한다. 관절 ID·온도·경과/5초를 보여 주고 정상 복귀하면 해제한다. 클릭 확인창은 띄우지 않는다. 중단된 경우에는 기존 오류와 연결 복구 흐름을 사용한다.

현재 하드웨어와 단위, 리더 보정 등록, 이전 OMX 기록 호환 정책은 README.md의 2026-09-22 기준을 따른다. 그리퍼 카메라 표시는 32×32 RGB, 상단 카메라는 D435 RGB이며 학습 입력에는 깊이값을 넣지 않는다.


## SO-101 전환과 깊이 보기 (2026-09-22)

앱 이름은 SO-101 모방 학습로 통일하며 이전 OMX 기록의 로봇 종류·원본 이름을 바꾸지 않는다. 녹화·새 학습·이어 학습은 SO-101 작업과 모델을 선택한다. 실제 관절 표시 단위는 몸체 ° / 그리퍼 %다. 상단 D435 영상은 같은 영역의 컬러·깊이 버튼으로 전환하고, 깊이 범례는 영상 아래에 표시해 영상을 가리지 않는다. 두 컬러 영상과 정렬된 16비트 깊이 원본을 함께 저장하되 ACT 입력은 두 컬러 영상만 유지한다. 깊이 없는 과거 기록에 가짜 깊이를 표시하지 않는다. 카메라 연결·깊이 수신이 확인되지 않은 상태를 정상으로 표시하지 않는다.
