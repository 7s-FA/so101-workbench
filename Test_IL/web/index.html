모델 삭제
선택한 모델과 이어 학습 상태를 이 PC에서 영구 삭제합니다. 삭제한 모델은 실행하거나 이어 학습할 수 없습니다. 같은 학습의 마지막 모델이면 학습 기록과 로그도 함께 삭제합니다. 원본 기록과 다른 학습의 모델은 유지합니다.

USB·전원을 연결하고 역할을 지정하세요. 연결만으로 팔이 움직이지 않습니다. 녹화에는 팔 2대와 카메라 2대가 필요합니다.

조작 순서
  1. 장치 연결 — 작업용 팔은 실제로 움직이는 팔(팔로워), 조작용 팔은 손으로 움직이는 팔(리더)입니다. 연결하면 자세와 영상만 표시합니다.
  2. 리더 따라가기 — 작업용 팔이 리더 자세로 이동한 뒤 따라갑니다. 이때 모터 힘이 켜집니다.
  3. 녹화 → 저장 또는 버리기 — 팔 조작은 계속됩니다. 다음 녹화를 바로 시작할 수 있습니다.
  4. 정지 (힘 유지) — 따라가기·실물 실행을 멈추고 현재 자세를 유지합니다. 녹화 중이면 녹화도 끝나며 저장 전 상태로 남습니다.
  5. 모터 힘 끄기 — 팔을 받친 뒤 힘을 해제합니다. 연결과 영상은 유지하고, 다시 조작하려면 리더 따라가기를 누릅니다.
