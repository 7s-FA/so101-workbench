# SO-101 테이블 티칭 테스트

재계산한 링크 질량을 적용한 SO-101과 TPU 집게로, 테이블 위 하위 지그에 놓인 **부품 A의 상단 → 구 → 하단**을 시험합니다. 운반로봇은 배치하지 않습니다. 실물과 같은 왼쪽 고정 집게 끝단 중심을 TCP로 사용합니다.

## 실행과 사용 순서

```bash
cd /path/to/Final_Arm
./Test_teach/start.sh
```

기존 Isaac 환경(`/path/to/isaac/env_isaaclab`)을 사용합니다. 기본 실행은 SO-101 시뮬레이션이며 모터 USB에 연결하지 않습니다.

1. **위에서 보기**로 부품 배치를 확인하고 상단·구·하단 중 하나를 선택합니다.
2. **TCP X/Y/Z 오프셋**, **집게 방향**, **집게 기울기**를 조정하고 **집기점 적용**을 누릅니다. 좌표는 선택 부품 원점 기준 mm입니다. 180° 기울기는 아래를 향합니다.
3. **상단 대기로 이동**으로 확인한 뒤 **집기점으로 이동**을 누릅니다. 하강은 부품 옆으로 3 mm 여유를 둔 수직 경로입니다. 집기 높이에 도달하면 고정 집게가 부품 옆으로 천천히 접근합니다. 집기점으로 이동만 눌러도 이 순서를 따릅니다.
4. **집고 올리기 시험**은 상단 대기 → 여유를 둔 하강 → 고정 집게 접근 → 닫기 → 100 mm 상승 → 3초 유지 순서로 실행합니다. 처음 40 mm는 수직을 유지하고, 이후에도 수직을 우선하며 손목 한계에서만 필요한 만큼 기울입니다. 성공 여부와 실제 상승량을 표시합니다. **정지**는 현재 가상 관절 위치를 유지합니다.
5. 세부 조정은 **관절 직접 조정**을 펼쳐 수행합니다. **현재 TCP 위치 사용**은 현재 위치를 부품 기준 집기점으로 환산합니다. 집게 방향·기울기는 해당 입력칸에서 정합니다.
6. **값 저장**으로 배치, 집기점, 현재 관절값, 실제 부품 위치를 저장합니다. 다음 실행에서도 저장한 집기점과 배치를 불러옵니다.

**하위 지그와 부품 지그 배치**에서 중심·회전·안착 오프셋을 바꿀 때는 **배치 적용 · 부품 재배치**를 먼저 누릅니다. 이 버튼은 부품을 새 배치에 놓고 동작을 정지합니다. 집기점 적용 버튼은 배치 입력을 적용하지 않습니다. 부품 선택을 바꾸기 전에도 입력을 적용하세요.

- 노랑: 하위 지그 중심
- 파랑: 개별 지그 원점
- 보라: 부품 외곽상자 중심
- 민트: 현재 부품 위치를 기준으로 한 집기 목표
- 빨강: 고정 집게 끝 TCP

## 배치와 거리

하위 지그는 제공된 220×148×6 mm STL입니다. 이전 부품 지그와 A 부품 STL을 사용하며, 빈 슬롯을 활용해 사이를 띄웠습니다. 상단 카메라 기준 왼쪽부터 상단·구·하단입니다.

U는 하위 지그 긴 변, V는 짧은 변, Z는 위쪽입니다. 로봇 베이스 좌표와 분리해 표시합니다. 기본 하위 지그 중심은 로봇 베이스 기준 **(210, 0, −2.4) mm**, 회전 −90°입니다. 테이블 높이 230 mm와 이 배치는 사진 기반 시험값이며 실측 설치 좌표는 아닙니다.

| 대상 | 지그 중심 U/V (mm) | 하위 지그 중심부터 수평 거리 | 지그 → 부품 원점 X/Y/Z (mm) |
|---|---:|---:|---:|
| 상단 | −72 / +36 | 80.5 mm | 0 / +4 / 8.05 |
| 구 | 0 / −36 | 36.0 mm | 0 / +4 / 1.60 |
| 하단 | +72 / +36 | 80.5 mm | 0 / +4 / 3.55 |

지그 바닥은 하위 지그 바닥보다 약 4.85 mm 위입니다. 부품을 지그 중심으로 강제로 옮기지 않고 **지그 안착 위치의 Y +4 mm 편심**을 보존했습니다. 높이는 STL 간 최초 접촉을 계산한 근사이며 충돌 여유 0.05 mm를 포함합니다. 표시하는 부품 중심은 외곽상자 중심으로 질량중심과 다를 수 있습니다.

출력물은 3MF 압출량/재슬라이싱을, 서보 6개는 55 g/개를 적용했습니다. 개별 메시 내부를 균일한 질량 분포로 근사해 질량중심과 관성 텐서를 계산했습니다. 실제 인필 구조·모터 내부 분포를 측정한 결과는 아닙니다. 고무·접착제, 별도 체결물, 보드, 추가 배선, 클램프·카메라 마운트 무게는 합계에서 제외합니다.

부품 A는 기존 PLA Matte 5% 조건의 추정 질량을 유지합니다. 상단 **8.908 g**, 구 **4.319 g**, 하단 **12.772 g**입니다.

**Razer Universal Grip Tape**는 두 집게 안쪽 끝에 별도 접촉 면으로 적용했습니다.

| 항목 | 적용값 | 근거 |
|---|---:|---|
| 두께 | 0.2 mm | 사용자 지정 근사값 |
| 폭 / 모양 | 8 mm / 팔각형 | 사진 기준 가정 |
| 정지 마찰계수 | 1.0 | 시험 시작용 추정 |
| 운동 마찰계수 | 0.8 | 시험 시작용 추정 |
| 반발계수 | 0 | 시험용 근사 |
| 마찰 결합 | max | 패드와 상대 표면 중 큰 값 사용 |

제품의 실측 마찰계수로 제시한 값이 아닙니다. GUI의 **접촉 조건**에서 변경할 수 있습니다. TPU와 패드는 강체로 근사하므로 변형·접착력·표면 미세 돌기를 재현하지 않습니다. 패드 두께를 TCP Z 좌표에 일괄 더하지 않았습니다. TCP는 지정한 고정 집게 끝단 중심을 유지합니다.

관절 구동은 위치 제어입니다. 팔의 시뮬 토크 상한은 2 N·m, 손목 굽힘·회전은 각각 0.6 N·m입니다. 집게 닫기 상한은 0.15 N·m이며, 상승·유지에는 상단/하단 0.08 N·m, 구 0.12 N·m를 사용합니다. 실물 모터 전류·토크 보정값은 아닙니다. 그리퍼 열림은 0~100%로 표시합니다.

## 저장 결과

**값 저장**은 아래 두 파일을 갱신합니다.

- `config/so101_scene.json`: 다음 실행에 사용할 배치와 부품별 집기점·방향·높이·마찰 설정.
- `teaching/so101_layout.json`: 위 설정, 중심 간 거리, 현재 관절값, TCP, 실제 시뮬레이션 부품 좌표를 함께 저장한 기록.

저장 파일의 `nominal_step_candidates`에는 부품별 **hover(상단 대기), descend(하강), close(닫기), lift(상승)** 관절값과 TCP 위치·자세 후보가 들어갑니다. `joint_pose`는 현재 시뮬레이션에서 읽은 값이고, 스텝 후보는 저장한 배치를 기준으로 계산한 값입니다. 도달 불가능한 설정은 오류를 기록하고 화면에도 표시합니다.

위치·각도 후보를 얻는 도구이며 이 파일을 저장해도 실물 보정 완료나 모방학습 데이터 수집 완료로 표시하지 않습니다. 실물 팔로워 JSON은 변경하지 않습니다.

## OpenCV 티칭으로 집기값 보내기

1. 이 시뮬레이션에서 **값 저장**을 눌러 `config/so101_scene.json`을 갱신합니다.
2. `opencv-teach`의 **장비 설정 → 지그·집기 목표 → 시뮬레이션의 집기값 가져오기**를 엽니다.
3. 부품을 선택하고 **후보 3개 저장 · 선택 부품 열기**를 누릅니다. 선택한 동작 구성으로 상단·구·하단 후보를 만들며, 기존 에피소드·보정은 덮어쓰지 않습니다.
4. 실물의 지그 크기·설치 높이·도킹 방향을 확인합니다. **팔 안전 자세 → 도킹 완료·정지 → 지그 기준 저장** 후 실물을 보며 ±로 맞추고 **맞춘 위치를 목표에 반영**합니다. 테이블 시험에서는 지그를 고정한 상태에서 기준을 읽습니다.
5. 연결된 단계의 경로를 다시 계산하고 에피소드를 저장합니다. 팔에 가려져도 같은 도킹 기준을 사용하며, 지그를 움직였거나 재도킹했다면 다시 읽습니다.

OpenCV에서는 저장된 배치와 집기점으로 **지그 중심 기준 목표 X·Y·방향**을 계산하고, 실제 작업에서는 카메라로 저장한 이번 도킹의 지그 위치와 결합합니다. 집기 Z는 로봇 베이스 기준 절대 높이이므로 실물 설치에 맞춰야 합니다.

시뮬의 관절값을 그대로 실물에 재생하는 절차가 아닙니다. 질량·패드 마찰은 후보의 참고 조건이며 실물 파지력·토크를 자동 설정하지 않습니다. 현재 저장된 후보 3개는 각각 한 부품을 집고 100mm 올린 뒤 같은 자리에 놓고 안전 자세로 돌아오는 9단계입니다. 세 부품은 개별 에피소드로 실행합니다.

보정 상태와 버튼별 저장 차이는 [OpenCV 사용방법](../OpenCV_teach/사용방법.md#simulation-import) 및 [도킹 기준 저장](../OpenCV_teach/사용방법.md#docking-reference)을 참고하세요.

## 검증

```bash
# GUI 없는 정지 장면 확인
./Test_teach/start.sh --headless --preview
# 세 부품의 접촉 기반 파지 시험
./Test_teach/start.sh --headless --verify --part all
# 한 부품 / 마찰 민감도 시험
./Test_teach/start.sh --headless --verify --part ball --friction 0.8
# 코드 회귀 검사
PYTHONPATH=Test_teach /path/to/isaac/env_isaaclab/bin/python -m unittest discover -s Test_teach/tests
```

파지 시험은 부품을 집게에 붙이는 조인트나 위치 강제 갱신을 사용하지 않습니다. 배치 초기화 때만 부품 위치를 되돌립니다. 상승 후 3초 유지 구간 끝에 요청 높이에서 10 mm 이내로 도달하고(최소 15 mm), 최고점 대비 내려앉음이 5 mm 미만이면 들어 올림으로 판정합니다. 접촉 조건·위치 후보 비교용 판정으로 실물 파지나 충돌 없는 경로를 보증하지 않습니다.

결과는 `outputs/so101_preview/`, `outputs/so101_trial/`, `outputs/so101_ui_smoke/`에 기록합니다. `report.json`에 이번 실행의 설정과 실제 상승량, 판정이 있습니다. 파지 실패 종료 코드는 2, 실행 오류는 1입니다. `--ui-smoke`는 GUI 조작과 임시 저장을 확인한 뒤 자동 종료합니다.

`scripts/prepare_so101.py`는 원본 모델을 복사하고 물성·초기 배치를 생성하는 개발용 도구입니다. 사용자가 변경한 설정을 보존하려면 다시 실행하지 마세요. 일반 실행에서는 자동 실행하지 않습니다.

## 2026-09-22: 지그 간섭·준비 자세·유지 힘 조정

- 구 지그를 90° 돌리고 구의 기준 방향을 보정하여 집게 방향은 유지했습니다. 지그 안착 편심은 보존합니다.
- 준비 자세와 안전 복귀 자세를 모두 마지막 사진처럼 집게가 앞쪽 아래를 향하는 동일한 자세로 구성했습니다. 앞선 위로 세운 사진은 기준에서 제외했습니다. 사진을 근사한 모델 각도이며 실물 엔코더에서 읽은 값이 아닙니다. 이 문단은 당시 준비 자세 기록이며, 현재 영점·안전 자세는 아래의 새 영점 적용 항목을 따릅니다.
- **안전 자세로 복귀** 버튼은 물체가 올라가 있으면 배치 초기화를 요구합니다. 집기 위치 근처에서는 먼저 지그 위로 후퇴하고 안전 자세로 갑니다.
- 고정 집게 구조를 고려해 하강 시의 3 mm 여유와 최종 접촉 위치를 분리했습니다. 여유 위치에서 바로 닫아 부품을 지그 안에서 밀어내던 동작을 바꿨습니다.
- 상승은 TCP 기준 100 mm입니다. 수직 상태를 우선하고 지그 위 40 mm부터 필요할 때만 기울입니다. 현재 명목 경로의 최종 기울임은 상단/하단 약 14°, 구 약 24°이며 최대 25°입니다. 손목 굽힘 상한 앞에 2° 여유를 두었습니다.
- 손목 최대 0.6 N·m, 집게 닫기 최대 0.15 N·m로 제한했습니다. 닫기 단계 후 상승·유지에는 상단/하단 0.08 N·m, 구 0.12 N·m를 사용합니다. **접촉 힘 센서로 힘을 추정하는 제어는 아니며**, 단계별 토크 상한을 적용하는 물리 시뮬레이션입니다.
- 보고서의 `simulated_load`는 implicit actuator의 PD 토크 추정입니다. 실제 모터 토크나 접촉 힘 측정으로 해석하지 마세요. 실제 전류·토크 설정은 변경하지 않았습니다.

### Test_IL의 고온 지속시간 검사

`teach_io.worker --reference-control --sustained-temperature`는 Test_IL이 명시적으로 사용하는 정책입니다. 구동 중 65°C 이상 연속 5초, 시작 전 65°C 이상 즉시 차단, 고온 감시 공백 1.5초 초과 즉시 차단을 적용합니다. 관절·읽기 경로별 타이머는 같은 연결에서 유지하고 정상 측정에서만 해당 타이머를 초기화합니다. 해당 옵션이 없는 Test_teach와 읽기 도구는 기존 55°C 즉시 차단을 유지합니다. 전압·모터 알람·통신·과부하 검사와 EEPROM 설정은 바꾸지 않습니다.

## 2026-09-22 새 모터 영점 적용

사용자가 확인한 팔로워 보정 JSON을 `motor_reference`에 저장하고 OpenCV와 같은 모델 오프셋 0°를 사용합니다. 초기·안전 관절값은 이전 물리적 엔코더 위치를 유지하도록 새 영점으로 환산했습니다. 몸체 관절 슬라이더는 현재 보정의 모터 틱, 집게는 0~100입니다. 부품 배치·안착 편심·집기점·질량·마찰 조건은 유지했습니다.

회귀 검사 125개가 통과했고, 세 부품의 접촉 파지 시험도 통과했습니다. 상승량은 상단 100.285mm / 구 100.995mm / 하단 97.379mm였습니다. 이는 물리 시뮬레이션 결과이며 실제 모터 구동이나 실물 집기 시험은 아닙니다. OpenCV의 기존 에피소드 6개도 같은 기준으로 갱신했습니다.
